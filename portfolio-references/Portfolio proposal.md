## What he will defend

Every project names its tools, and only tools Wan Zayd will defend under questioning: OutSystems O11 and ODC, SQL and Aurora PostgreSQL, REST and integration work, and architecture practice such as C4 diagrams and technical design documents. React, AWS and .NET/C# stay off the page, though his LinkedIn lists them. Flutter appears only on the Minor Projects that used it.

## The taste: a 14 kilobyte page

The whole page aims to stay under 14 kilobytes compressed, so it loads on 3G without waiting. The figure is a target, not a limit. A web font or a photograph would each cost more than the page can afford, so both stay out and the typography carries the design.

Marks are the only images. Five organisations have compact vector marks, costing 6,267 bytes together, and they appear wherever an employer, client or tool is named. The rest appear in type. With the prose, markup and stylesheet estimated at 5 to 6 kilobytes, the page comes to about 11 to 12 kilobytes, inside the target. That estimate has not been checked against a built page.

This proposal sets the budget, not the look. Colour, type and layout belong to the artistic direction, which Wan Zayd will set in a separate document, using a skill he builds for it.

## What it leaves out

- **A blog**: writing is a continuing commitment, not a build, and can be added later without a rebuild.
- **Social reach**: this is a portfolio, not a following.
- **A custom domain**: GitHub hosting is free; the cost is that his name is harder to find in search.
- **Any server, form or database**: email and LinkedIn do the same job, and nothing can break.
- **A CV download**.
- **Music and session work**: the site stays strictly professional.
- **The Maybank design-ownership story**: Claude recommended it as design evidence; he chose to leave it out.
- **Relative time**: no "currently", no "last updated". Undated content cannot look abandoned.

## How it runs

No date drives this work; it is a continuing personal project, built in stages. The site runs on GitHub at no cost. If GitHub is down, the site is unreachable and no fallback exists, and he accepts that because the page carries nothing urgent. JavaScript is used only where CSS cannot do the work, so a dropped connection still leaves readable content.

The one thing that can go stale is the timeline's "present". If he changes employer and does not update the page, that entry becomes wrong.
